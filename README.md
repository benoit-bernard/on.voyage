# ON.VOYAGE

Guide de voyage audio géolocalisé qui apprend les goûts du voyageur et privilégie les lieux moins fréquentés.

- Spécification : [`docs/CAHIER_DES_CHARGES.md`](docs/CAHIER_DES_CHARGES.md) · règles agents : [`.github/copilot-instructions.md`](.github/copilot-instructions.md)
- Stack : .NET 10, Aspire, WolverineFx, MAUI Blazor Hybrid (Android, iOS) + PWA Blazor WebAssembly, RCL partagée.
- Lancer : voir [`docs/MOBILE.md`](docs/MOBILE.md). Tests : `dotnet test --solution OnVoyage.slnx`.

L'ancien site statique (GitHub Pages) a été retiré ; `CNAME` est conservé pour le domaine.
